# Source data for the main figures (Supplementary Data)

This document maps each main manuscript figure to its source-data file, as
requested during revision. The files are generated by `14_source_data.py` and
written to `source_data/`.

Figures 1 and 2 are a pipeline schematic and representative images; they plot no
underlying data and therefore have no source-data file.

## Figure → Supplementary Data mapping

| Figure | Source data file | Supplementary Data # |
|---|---|---|
| Figure 3 — image quality metrics (SSIM, PSNR, RMSE, NCC) | `SourceData_Fig3.xlsx` | Supplementary Data 1 |
| Figure 4 — TLE regional concordance (4B, 4C, 4D) | `SourceData_Fig4.xlsx` | Supplementary Data 2 |
| Figure 5 — MCI regional concordance (5C and per-region Δr) | `SourceData_Fig5.xlsx` | Supplementary Data 3 |
| Figure 6 — Cohen's d quadrants and cortical surface maps | `SourceData_Fig6.xlsx` | Supplementary Data 4 |

> The Supplementary Data numbers above are the numbering we propose. If the
> journal assigns different numbers, update this table and the Data Availability
> statement below to match.

## What is in each file

Every workbook has a `data_dictionary` sheet defining each column, plus one
sheet per figure panel. Sheet names encode cohort, atlas (`DKT` or `HO` =
Harvard-Oxford) and split (`cv` = cross-validation folds 0–9, `test` = held-out
folds 10–11).

**`SourceData_Fig3.xlsx`** — one sheet per cohort:
- `Fig3_<cohort>_per_subject` — per-subject SSIM/PSNR/RMSE/NCC for synthetic PET
  and ASL against real FDG-PET, with the subject's fold and split. The held-out
  panel of Figure 3 plots these values directly.
- `Fig3_<cohort>_cv_fold_means` — the mean of each metric within each of the 10
  cross-validation folds. The cross-validated panel of Figure 3 plots one point
  per fold, so these are the plotted values.

**`SourceData_Fig4.xlsx`** (TLE) and **`SourceData_Fig5.xlsx`** (MCI):
- `Fig4BC_<atlas>_<split>` / `Fig5C_<atlas>_<split>` — per-region across-subject
  Spearman r against real FDG-PET, for FlowGAN and for ASL. Each region is one
  point in the boxplots of Figure 4B / 5C. `Delta_r_FlowGAN_minus_ASL` is the
  bar height in the Figure 4C forest plot.
- `Fig4D_<atlas>_<split>` — per-region sign congruency (proportion of subjects
  where the asymmetry direction agrees with real FDG-PET), for FlowGAN and ASL.
  These are the values plotted in Figure 4D.

**`SourceData_Fig6.xlsx`** — one sheet per cohort × atlas × split:
- `Fig6_<cohort>_<atlas>_<split>` — per-region Cohen's d for real PET, synthetic
  PET and ASL, the x/y coordinates of the Figure 6B comparison quadrant scatter,
  and the quadrant/category assignment with its plot colour. The `atlas_index_left`
  and `atlas_index_right` columns are the atlas indices used to render the
  shaded cortical-surface maps, so these sheets are the source data for the
  shaded maps as well as the scatterplots.

## Provenance

`14_source_data.py` repackages the analysis outputs rather than recomputing
them, so the source data cannot drift from the figures. Per-region values are
taken from `tables/11_per_fold_regional_analysis/` and `tables/revision_cohens_d/`,
which store them at full precision; quality metrics come from
`tables/10_per_fold_quality_metrics/`.

The per-region supplementary tables in `tables/revision_supplementary_tables/`
report the same quantities rounded to three decimals for readability. The source
data here is unrounded.

## A note on recomputing p-values from these files

The values in these workbooks match the analysis to within floating-point
serialisation error (~1e-16), which is far below any meaningful precision and
does not affect any plotted point visibly.

One consequence is worth stating explicitly. The Wilcoxon signed-rank test is
rank-based, so where two regions have nearly identical FlowGAN-minus-ASL
differences, a 1e-16 serialisation difference can swap their ranks and shift the
p-value slightly. This affects only the held-out panels, which have few subjects
and therefore closely spaced ranks:

| Panel | p recomputed from source data | p reported |
|---|---|---|
| TLE / DKT, held-out | 0.0072 | 0.0064 |
| TLE / Harvard-Oxford, held-out | 0.0027405 | 0.0027403 |
| MCI / Harvard-Oxford, held-out | 0.0071 | 0.0070 |

All four cross-validated panels, and the MCI/DKT held-out panel, reproduce their
reported p-values exactly. In every case above the two values fall on the same
side of 0.05 and the conclusion is unchanged; the effect sizes and the counts of
regions favouring FlowGAN are identical either way. The plotted points
themselves — the per-region correlations that make up each box — are unaffected
at any visible precision.

To reproduce the reported statistics exactly, run the analysis itself
(`python run_all.py`), which computes them without a serialisation round-trip.
